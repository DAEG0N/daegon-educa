# Daegon Educa

Daegon Educa is an original academic-management interface for school administration.

The product concept is informed by real administrative experience with academic systems used for student and teacher registration, enrollment, subjects, calendars, grade entry and report-card closing. It is not a copy of Activesoft or any third-party software; the UI, naming and workflows are original.

## Modules
- Dashboard
- Students
- Teachers
- Enrollments
- Subjects
- Academic calendar
- Grades and report cards

## Demo workflows
- Create students
- Start enrollments
- View enrollment pipeline
- Edit grades and calculate averages
- Close report cards
- Global search with Ctrl+K
- Light/dark mode

## Stack
HTML5, CSS3 and JavaScript.

All people, grades and school data in this repository are fictional demo data.

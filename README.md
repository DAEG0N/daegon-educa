# Daegon Educa

Daegon Educa is an original school-management product concept focused on day-to-day administrative and academic workflows.

The structure is informed by real operational experience with school-management software and by common module patterns found in Brazilian school ERPs. It is **not a copy of Activesoft, Escolaweb or any third-party product**.

## Product areas

### Secretaria
- Students and guardians
- Enrollment workflow
- Digital documents
- Global record search

### Acadêmico
- Classes and curriculum
- Class diary
- Bulk attendance
- Grade entry
- Grade confirmation
- Report-card configuration and publication

### Gestão
- Finance overview
- Communications
- Student / guardian / teacher portals

## Functional demo workflows
- Add a student
- Start an enrollment
- Search records
- Register attendance in bulk
- Enter and batch-apply grades
- Calculate averages
- Confirm grades
- Configure and publish report cards

## Stack
- HTML5
- CSS3
- JavaScript
- Local front-end demo data

All people, financial values and academic data are fictional.
